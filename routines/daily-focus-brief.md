# Daily focus brief

**When it fires:** Weekday morning: send today's #1 focus brief with restated week goals and Open Items ordered for the day.

## Job text

Run Daily focus brief for the user (their timezone).

Use locked month/week goals from memory. Open Items: use the Open Items location from memory (Notion or equivalent). In the brief, always surface same-day meeting talking points from memory + due-today Open Items. Restate week #1 (and #2 if any) in full plain sentences — never opaque shorthand alone. Message them the brief (today's #1 first). Stay quiet only if Open Items/calendar are unreachable and you already reported that auth failure last run (then pause this routine).
