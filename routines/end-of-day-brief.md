# End of day brief

**When it fires:** Weekday late afternoon: close-out brief with done today, urgent-tonight, week goals progress, and tomorrow preview.

## Job text

Run the End of day brief skill. Produce the user's weekday close-out: what got done today, anything truly urgent before logging off tonight (or say clear — log off), restate this week's goals in full plain sentences with progress, and preview tomorrow (calendar + provisional tomorrow's #1). Message them the brief in chat. Default is always send on weekdays; stay quiet only if the skill has nothing and the saved quiet rule applies.
