# Friday weekly wind-down

**When it fires:** Friday afternoon close: Open Items cleanup, weekly product/role update, skill review, lock next week goals, then Friday EoD.

## Job text

Run Friday weekly wind-down for the user (their timezone). Start at phase 0; do not skip ahead.

Phase 0: Open Items Cleanup — stale/duplicate/obsolete pass; report keep vs closed; then continue.
Phase 1: Weekly product update (or the user's weekly role update) — draft for review; never post to the product channel without explicit go.
Phase 2: Weekly skill review — flag proposed edits; do not auto-edit skills.
Phase 3: Propose next week's goals (#1 / #2 / #3) as action sentences; wait for sign-off before locking.
Phase 4: End of day brief — Friday weekend close.

Write phase to memory each advance. If this Friday already finished, stay quiet on a duplicate fire. Resume in-progress Fridays at the stored phase.
